# Turkish / English UI

The interface language is picked with the `TR | EN` switch in the sidebar footer. The choice is kept in
Herdr's shared store as `shared("ui.lang")`: `"tr"` (the default, also when the value is missing or unknown)
or `"en"`. `setShared` redraws every mod, so the language changes at once.

## The same helper in every mod

```js
// UI language (shared "ui.lang": "tr" default | "en"); see I18N.md (package root)
const tx = (tr, en) => (shared("ui.lang") === "en" ? en : tr);
```

- `shared` comes from `"herdr"`.
- Call `tx(...)` only while rendering or handling an event, never in top-level constants: those are computed
  once when the mod loads and would not follow a later switch. Keep top-level tables as `{ tr, en }` objects
  and pick with `tx(o.tr, o.en)` at render time.
- Translated: visible text, tooltips, empty states, notifications, error messages, units.
- Not translated: element ids, shared keys, command names, file paths, provider/model names, and the task and
  brief text sent to agents (the task presets and team prompts are Turkish on purpose).
- Placeholders of text inputs are fixed when the input is created (`InputState` has no placeholder setter);
  long-lived panels draw their hint as an element under the input instead, so it follows the switch.

## Herdr's own mods

Herdr's shipped mods are not edited in place. They are cloned (`herdr-app do mod.clone --name <mod> --as <mod>-tr`),
the clone is translated, and the layout points its block at the clone. The terminal right-click menu is chosen by the
layout's root `"terminal_menu": "menu-tr"`.
